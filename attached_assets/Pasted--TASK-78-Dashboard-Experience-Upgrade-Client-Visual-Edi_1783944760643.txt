# TASK 78 — Dashboard Experience Upgrade (Client Visual Editor + AI Assistant + Website Health Center)

**Priority:** CRITICAL

## Project Goal

Further evolve the **FSTS Website Operating System™ (FSTS-WOS)** into a premium website management platform.

The dashboard should allow clients to confidently manage their websites without needing web design experience while protecting the professional appearance of every site.

These features become part of the **FSTS-WOS™ Core Platform** and will automatically be available for every future client website.

---

# FEATURE 1 — Responsive Live Preview Studio™

## Objective

Allow clients to preview exactly how their website will appear before publishing.

Every content editor should include a real-time preview panel.

Supported devices:

* Desktop (1920px)
* Laptop (1440px)
* Tablet Landscape
* Tablet Portrait
* iPhone
* Android Phone

Supported editors:

* Homepage
* Hero Sections
* Courses
* Events
* Blog / Knowledge Center
* Team Members
* Testimonials
* Footer
* Contact
* Careers
* Forms
* Popups

Preview updates instantly while editing.

No refresh.

No republish required.

---

### Preview Controls

Include:

* Desktop / Laptop / Tablet / Mobile selector
* Rotate device
* Zoom controls
* Safe-area overlays
* Pixel dimensions
* Responsive breakpoints
* Scroll preview
* Animation preview
* Mobile navigation preview
* Dark / Light preview
* Print preview (optional)

Publishing workflow:

Draft

↓

Preview

↓

Validation

↓

Publish

Never publish without preview.

# FEATURE 4 — Website Health Command Center™

## Objective

Provide every client with a single dashboard showing the overall health of their website.

This should become the first screen clients see after logging in.

The Command Center should give clients confidence that their website is healthy while helping them quickly identify issues before they affect visitors.

---

## Overall Website Health Score

Display a single overall score from **0–100** based on weighted categories.

Example:

**Website Health: 96 / 100**

Status:

* 🟢 Excellent
* 🟡 Needs Attention
* 🔴 Critical Issues

---

## Individual Health Scores

Display separate score cards for:

* Performance
* SEO
* Accessibility
* Security
* Forms & Lead Capture
* Email Delivery
* Square Payments
* Media Optimization
* Content Quality
* Mobile Experience
* Uptime
* Backup Status

Each score should include:

* Current Status
* Last Scan
* Trend (Improving / Stable / Declining)
* Recommended Actions

### Security

* Secure headers
* Environment variable validation

### Forms

* Contact forms
* Event registration
* Course registration
* Newsletter forms
* Form validation
* Spam protection
* Submission delivery

### Payments

* Square connection

## PROJECT STANDARD

The **FSTS Website Operating System™** should become a premium, enterprise-grade website management platform that combines the ease of use of WordPress with the reliability of a protected design system.
