# Task 3 — Temporarily Disable Public Access to `/blog`

The page must not remain publicly available merely because it was removed from navigation.

Temporarily disable access to:

```text
/blog
```

and any associated public article routes, such as:

```text
/blog/[slug]
```

if those routes depend on the unfinished Dashboard integration.

## Preferred implementation

Use a centralized feature flag such as:

```ts
const FEATURES = {
  knowledgeCenter: false,
} as const;
```

or the equivalent architecture already used by the project.

When disabled:

- Do not render the page publicly.
- Do not fetch unfinished Dashboard article data.
- Do not expose partially working content.
- Do not show a broken or empty article listing.

## Route behavior

Use the behavior most consistent with the existing application:

### Preferred

Return the framework’s proper not-found response.

For Next.js, this may be:

```ts
notFound();
```

This should result in a real HTTP 404 response where supported.

### Acceptable alternative

Temporarily redirect visitors to the homepage:

```text
/
```

Use a temporary redirect, not a permanent redirect, because the Knowledge Center will return later.

Do not redirect `/blog` to the general Contact page.

Do not return a visually blank page with HTTP 200.
