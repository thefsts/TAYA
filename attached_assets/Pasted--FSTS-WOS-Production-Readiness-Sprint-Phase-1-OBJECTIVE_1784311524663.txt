# PRIORITY 1 — MULTI-TENANT SECURITY

This is the highest priority.

Audit every Convex function that accepts a `siteId`.

Anywhere a client-supplied `siteId` is trusted, replace it with proper authorization.

Apply `requireSiteAccess()` consistently across every site-scoped mutation and any sensitive queries.

This includes (but is not limited to):

* Articles
* Courses
* Events
* Site Settings
* Homepage
* Footer
* Contact
* SEO
* Forms
* Media
* Testimonials
* Reviews
* FAQ
* Future modules

SuperAdmin functionality must remain intact.

Agency Admin permissions must continue working correctly.

---

# BUILD TENANT ISOLATION TESTS

Create automated tests proving:

* User from Site A CAN access Site A.
* User from Site A CANNOT read Site B.
* User from Site A CANNOT create data in Site B.
* User from Site A CANNOT update Site B.
* User from Site A CANNOT delete Site B.

Verify permissions for:

* SuperAdmin
* Agency Admin
* Client Admin
* Staff
* Portal User

Every permission path must be validated.

No manual testing.

Automated tests only.

# PRIORITY 2 — REMOVE CLIENT WEBSITE FROM PLATFORM

After tenant isolation is complete:

Verify the dedicated Corsair repository contains the complete website.

Then remove:

```

```


so that any client website source code added to the platform repository is detected and causes the boundary check to fail.
