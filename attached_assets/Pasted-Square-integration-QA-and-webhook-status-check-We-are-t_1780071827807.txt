WEBHOOK REQUIREMENT
===================

Yes, we need Square webhook setup before production live.

Please confirm whether this route exists:

/api/square/webhook

Webhook should handle Square events such as:

* payment.created
* payment.updated
* order.created
* order.updated
* refund.created
* refund.updated

Webhook must verify the Square webhook signature using:

SQUARE_WEBHOOK_SIGNATURE_KEY

Do not log sensitive payment/token data.

SQUARE DASHBOARD WEBHOOK SETUP
==============================

If webhook route is ready, provide the exact Square Dashboard setup instructions.

Production webhook endpoint should be:

https://corsairtacticalsolutions.com/api/square/webhook

Sandbox webhook endpoint for testing should be:

https://corsair-tactical-solutions.vercel.app/api/square/webhook

or the correct current Vercel preview/production URL if different.

In Square Developer Dashboard:

* Open the Square app
* Go to Webhooks
* Add webhook subscription
* Add endpoint URL
* Select required events
* Copy webhook signature key
* Add it to Vercel as:
  SQUARE_WEBHOOK_SIGNATURE_KEY
