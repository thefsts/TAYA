# TASK 83 — Version 1.0 Go-Live Readiness & Multi-Site Validation

**Priority:** CRITICAL

## Project Goal

Prepare the FSTS Website Operating System™ (FSTS-WOS™) for **Version 1.0 Production Release**.

The immediate objective is:

1. Make **Corsair Tactical Solutions** the first fully managed production website.
2. Validate that the platform can manage **multiple websites simultaneously** without additional development.
3. Establish the dashboard as the permanent website management platform for all future FSTS client websites.

---

# PRIMARY GOALS

## Goal 1 — Complete Corsair Production Integration

Corsair Tactical Solutions will become the first production client managed entirely through the dashboard.

Complete every remaining dashboard-to-website connection so the live website reads from Convex instead of static source files.

The following must publish live from the dashboard:

* Homepage
* Hero content (where applicable)
* Homepage sections
* Courses
* Events
* Blog Articles
* Testimonials
* FAQ
* Footer
* Contact Information
* Navigation
* SEO
* Team Members
* Downloads & Resources
* Policies
* Announcement Banner
* CTA Manager

No hardcoded content should remain unless intentionally used as a fallback.

---

# Goal 2 — Validate Multi-Tenant Operation

Verify the dashboard is fully capable of managing multiple client websites at the same time.

Confirm:

* Complete site isolation using `siteId`
* Independent media libraries
* Independent forms
* Independent SEO
* Independent payment settings
* Independent email settings
* Independent client portal settings
* Independent memberships
* Independent automation settings
* Independent backups
* Independent activity logs
* Independent version history

No client data may ever be visible across websites.

---

# Goal 3 — Production Website Template

Corsair becomes the reference implementation for every future client website.

Every future site should require configuration—not redevelopment.

Implement a reusable onboarding workflow:

* Create Site
* Assign Domain
* Assign Client Administrator
* Seed Default Content
* Configure Modules
* Configure Payments
* Configure Email
* Configure Branding
* Publish

No manual database work should be required.
