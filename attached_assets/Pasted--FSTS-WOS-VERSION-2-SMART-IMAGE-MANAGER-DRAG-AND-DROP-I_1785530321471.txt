# FSTS-WOS™ VERSION 2 — SMART IMAGE MANAGER™ (DRAG-AND-DROP IMAGE EDITOR)

## OBJECTIVE

Build a professional drag-and-drop image management system for the FSTS Website Operating System™ that allows clients to upload, crop, resize, position, optimize, and manage images directly within the dashboard.

This feature begins **only after Website #1 (Corsair Tactical Solutions) is successfully onboarded and the platform has been certified stable in production.**

This will become the standard image editor used throughout the entire FSTS Website Operating System™.

---

# DESIGN GOALS

The system must be simple enough for non-technical users while providing professional-quality image handling.

Clients should never need Photoshop, Canva, Paint, or another image editor just to prepare images for their website.

Everything should happen inside the dashboard.

---

# SUPPORTED MODULES

The Smart Image Manager™ must integrate with every area that uses images.

Including:

* Homepage
* Hero banners
* Sliders
* Services
* Team members
* Staff profiles
* Articles
* Blog
* Events
* Courses
* Testimonials
* Reviews
* Media Library
* Contact page
* Footer
* SEO images
* Social sharing images
* Logos
* Favicons
* Background images
* Future website modules

Build one shared image editor.

Do **NOT** create separate upload components for each module.

---

# IMAGE UPLOAD

Support:

* Drag-and-drop upload
* Click-to-upload
* Multiple image upload
* Progress indicator
* Upload queue
* Retry failed uploads
* Cancel uploads

Supported formats:

* JPG
* JPEG
* PNG
* WebP
* AVIF (when supported)

SVG uploads must use a separate secured validation path.

---

# IMAGE EDITOR

After upload, open a visual editor.

Allow clients to:

* Drag the image
* Zoom
* Rotate
* Flip horizontally
* Flip vertically
* Crop
* Resize
* Reset
* Cancel
* Save

Changes must be previewed before saving.

---

# ASPECT RATIO PRESETS

Provide built-in presets for:

* Original
* Free Crop
* Square (1:1)
* Landscape (4:3)
* Wide (16:9)
* Portrait (3:4)
* Social Portrait (4:5)

Website-specific presets:

* Hero Banner
* Homepage Banner
* Service Card
* Article Thumbnail
* Course Thumbnail
* Event Thumbnail
* Team Photo
* Testimonial Photo
* Review Photo
* Logo
* Favicon

These dimensions should come from a shared configuration rather than being hard-coded in each module.

---

# FOCAL POINT SYSTEM

Allow the client to click or drag a focal point.

Store:

* X coordinate
* Y coordinate

Responsive layouts should use the focal point when applying image positioning.

The focal point should keep:

* Faces
* Products
* Logos
* Key objects

visible across desktop, tablet, and mobile layouts.

---

# RESPONSIVE PREVIEW

Show live previews for:

* Desktop
* Tablet
* Mobile

Clients must be able to see exactly how the image will appear before saving.

---

# IMAGE OPTIMIZATION

Automatically generate optimized versions.

Store:

* Original
* Thumbnail
* Small
* Medium
* Large
* Hero

Preferred formats:

* WebP
* AVIF (when supported)

Preserve transparency where required.

# WEBSITE PREVIEW

Allow users to preview the selected image within the page where it will appear before saving changes.

---

# ACCESSIBILITY

Support:

* Keyboard navigation
* Screen readers
* Focus indicators
* Accessible labels
* High-contrast controls

Users who cannot drag images must still be able to reposition them using keyboard controls.

---

# SECURITY

Enforce:

* Tenant isolation
* Permission validation
* MIME validation
* File size validation
* Malware protection
* Image dimension validation
* Upload ownership

Do not trust client-side validation.

---

# PERFORMANCE

Use optimized processing.

Do not block the browser while processing large images.

Generate derivatives in the background where appropriate.

Use thumbnails throughout the dashboard instead of loading original files.
