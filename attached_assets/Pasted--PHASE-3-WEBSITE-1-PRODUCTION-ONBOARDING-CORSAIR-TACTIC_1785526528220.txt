# PHASE 3 — WEBSITE #1 PRODUCTION ONBOARDING (CORSAIR TACTICAL SOLUTIONS)

## OBJECTIVE

Use **Corsair Tactical Solutions** as the official production acceptance test and the first live client website.

Do **not** create a temporary production tenant.

The onboarding process for Corsair must become the standard operating procedure (SOP) for every future client.

No shortcuts.

No direct database edits unless required to repair a verified defect.

Everything should occur through the same workflows every future customer will use.

---

## STEP 1 — VERIFY CORSAIR REPOSITORY

Confirm:

* Production repository is current.
* Build succeeds.
* Environment variables are documented.
* Required assets are present.
* No development configuration remains.
* Deployment configuration is current.
