============

Use the website course/service prices and fees as the source of truth.

Square must match the website prices.

The customer checkout total must include:

* base class price
* required fees

====================
IMPORTANT PRICE RULE
====================

Do NOT let Square, the frontend form, or user input override the correct price.

The server must calculate the final total from the website pricing catalog.

Frontend can display prices, but backend/server must validate and calculate:

finalTotal = baseCoursePrice + requiredFees + selectedOptionalAddOns

====================
CENTRAL PRICING FILE
====================

Create or update one central pricing/catalog source, such as:

src/lib/pricing.ts
or
src/data/catalog.ts

This file must include every payable class and service.

Each course/service should support:

```ts
type PriceFee = {
  id: string;
  label: string;
  amountCents: number;
  required: boolean;
  locked: boolean;
  description?: string;
};

type CatalogItem = {
  id: string;
  slug: string;

  squareCatalogItemId?: string;
  squareVariationId?: string;

```

====================
REQUIRED / LOCKED FEES
======================

If a course has a range fee or any required class fee, that fee must be locked.

Locked means:

* it is shown clearly to the customer
* it is included in the checkout total
* it cannot be unchecked
* it cannot be removed
* it cannot be modified by frontend input
* server always includes it when calculating payment

Example:

```ts
requiredFees: [
  {
    id: "range-fee",
    label: "Range Fee",
    amountCents: 2500,
    required: true,
    locked: true,
    description: "Required range fee for this class."
  }
]
```

If the range fee is required for the class, it must always be charged.

SERVER-SIDE TOTAL CALCULATION
=============================

Backend must calculate the total.

Frontend should send only:

* course slug/id
* selected option id if needed
* selected optional add-on ids
* student/customer info
* waiver status

Server must:

1. Look up course by slug/id
2. Validate course is active
3. Validate course is not contactOnly
4. Add base price
5. Add all requiredFees automatically
6. Add only valid selected optionalAddOns
7. Reject unknown add-ons
8. Reject tampered prices
9. Create Square Order/Payment with the server-calculated total
