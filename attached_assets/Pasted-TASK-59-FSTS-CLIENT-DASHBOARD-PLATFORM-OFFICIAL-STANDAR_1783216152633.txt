TASK 59 — FSTS CLIENT DASHBOARD PLATFORM (OFFICIAL STANDARD FOR ALL FUTURE FSTS WEBSITES)

PRIORITY: CRITICAL

PROJECT OBJECTIVE

The FSTS Client Dashboard is now the OFFICIAL content management platform for Full Stack Tech Solutions.

This dashboard will be used for EVERY current and future FSTS client website.

Corsair Tactical Solutions will be the first production website connected to the platform and will serve as the reference implementation for all future projects.

The dashboard must be scalable, secure, modular, and reusable.

The dashboard is a CONTENT MANAGEMENT SYSTEM ONLY.

It is NOT a website builder.

SQUARE PAYMENT MANAGEMENT
==================================================

Clients must be able to manage their own Square payment configuration without requiring developer assistance.

Create a dedicated "Square Management" section.

Allow editing of:

• Square Application ID
• Square Location ID
• Catalog Item IDs
• Course Payment Links
• Event Payment Links
• Button-to-Product Mapping
• Production/Sandbox selection
• Active products
• Inactive products

Allow clients to:

Update pricing

Replace payment links

Assign products to courses

Assign products to events

Enable/Disable products

Reconnect Square catalog items

WITHOUT requiring any code changes.

The dashboard must automatically preserve the existing secure payment workflow.
