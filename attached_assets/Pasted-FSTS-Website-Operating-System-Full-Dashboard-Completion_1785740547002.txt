Project

FSTS Website Operating System™
Repository: "https://github.com/thefsts/FSTS-client-Dashboard-for-sites-"

You are the Lead Developer responsible for completing the full dashboard platform.

The FSTS Website Operating System™ must function like a modern, multi-tenant WordPress-style platform that can power and manage many different client websites from one shared SaaS dashboard.

This is not a CRM.

Do not recreate functionality that belongs to Operon CRM.

---

1. Product Definition

The FSTS Website Operating System™ is the central website management platform used by FSTS and its clients to:

- Create websites
- Provision websites
- Connect existing websites
- Manage website content
- Manage pages
- Manage media
- Manage SEO
- Manage forms
- Monitor website health
- Manage website users
- Install premium website add-ons
- Publish website content to connected social media accounts
- Manage multiple websites from one account

It should feel similar to WordPress, but easier, more modern, multi-tenant, AI-assisted, and designed for businesses that do not want to manage plugins or technical hosting.
