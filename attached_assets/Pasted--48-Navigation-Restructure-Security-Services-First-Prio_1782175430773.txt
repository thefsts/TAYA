# 48. Navigation Restructure – Security Services First

**Priority:** HIGH

As part of repositioning Corsair Tactical Solutions as a professional security company, reorganize the navigation to improve usability while keeping the top navigation clean and uncluttered.

**Important:** This is a navigation and content organization update only. **Do NOT redesign or change the overall style, branding, colors, spacing, typography, animations, or layout of the website.** Preserve the current design language and user experience. Only reorganize the menu structure and hierarchy.

The goal is to reduce the number of primary navigation items while making it easier for commercial clients to find security services while still allowing training customers to easily access courses.

---

# Primary Navigation

Update the main navigation to the following order:

* **Corsair** *(rename the current "Home" menu item to "Corsair")*
* **About** ▼
* **Security Services** ▼
* **Training** ▼
* **Events**
* **Articles**
* **Contact**
* **Careers**

This should be used for both the desktop navigation and the mobile navigation.
