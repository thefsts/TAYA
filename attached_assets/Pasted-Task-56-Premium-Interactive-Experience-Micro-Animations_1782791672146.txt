Task 56 — Premium Interactive Experience & Micro-Animations

Priority: HIGH

Project Goal

Without changing the existing design, branding, or layout, transform the website into a premium, modern, interactive experience.

The website should feel like a high-end security company that also operates a professional training academy.

Animations should support the user experience—not distract from it.

Every animation must be smooth, fast, mobile friendly, and performance optimized.

==================================================

GENERAL REQUIREMENTS

==================================================

DO NOT redesign the website.

DO NOT change branding.

DO NOT change layouts.

DO NOT use gimmicky effects.

Maintain excellent Lighthouse performance.

Respect prefers-reduced-motion accessibility settings.

All animations should run at 60fps using GPU-accelerated CSS transforms where possible.

==================================================

HERO SECTIONS

==================================================

Enhance every hero section with subtle motion.

Examples:

• Slow cinematic background zoom (Ken Burns effect)
• Layered parallax
• Floating particles (very subtle)

• Animated headline entrance
• Fade-in content sequencing

The hero should feel alive while remaining professional.
