# WHY WE ARE DOING THIS

Mixing Dashboard development with website development has caused:

* Repository contamination
* Incorrect commits
* Deployment confusion
* Blocked builds
* Lost development time
* Difficult debugging
* Increased project risk

Separating the projects allows each to evolve independently while maintaining a clean architecture.
