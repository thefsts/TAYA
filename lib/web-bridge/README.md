# TAYA Web Bridge

The universal embed that connects ANY external website (regardless of who built
it) to TAYA content publishing. No customer-specific code. No framework
dependencies.

## Contract (v1)

### Embed attributes

| Attribute | Meaning |
|---|---|
| `data-taya-edit` | The §5 semantic content key (e.g. `home.hero.title`) |
| `data-taya-type` | Entry type: `text`, `image`, `url`, `list_item`, `button`, `link`, `repeatable` |
| `data-taya-label` | Human label (optional) |
| `data-taya-page` | Owning page path (best-effort, optional) |
| `data-taya-repeatable` | Marks a repeatable section |

### Endpoints (hosted on the Convex deployment HTTP actions)

| Method + Path | Auth | Returns |
|---|---|---|
| `GET /api/bridge/content?slug=` | public | `{version, bridgeVersion, domain, mode, publishedAt, pages, values}` — **published values only; drafts never appear** |
| `GET /api/bridge/draft?slug=&token=` | site verification token | `values` + `drafts` overlay (owner preview) |
| `POST /api/bridge/verify` | none | `{slug, matches, method, state, bridgeVersion}` (bridge_token ownership ping) |
| `POST /api/bridge/click` | none | `{ok, clicks}` click telemetry ingest |
| `GET /api/bridge/click?slug=&key=` | none | Same as POST (image-pixel fallback) |

Unknown slug → HTTP 404. Missing params → 400.

### Events dispatched (all bubble + composed)

- `taya:bridge-ready` — published values applied. `detail: {bridgeVersion, count}`
- `taya:element-click` — an editable element was clicked. `detail: {key, type, label, page}`
- `taya:preview-applied` — draft overlay applied. `detail: {bridgeVersion, draftCount}`

### Draft preview mode

Appending `?taya_preview=<verification-token>` to the site's URL makes the
snippet fetch `/api/bridge/draft` and overlay drafts on top of published
values. The token is the site owner's own verification token — the same
shared secret used to prove domain ownership (bridge_token method).

## Standard embed

```html
<!-- TAYA Web Bridge v1 -->
<script src="https://<convex-deployment>.convex.site/api/bridge/content?slug=<site-slug>"></script>
```

Or the self-contained snippet generated by `generateBridgeSnippet({convexHttpUrl, slug})`
(deterministic — a pure function of its inputs; see snippet.ts).

## Publishing model

External sites start as `DISCOVERED_EXTERNAL` (draft-only; publish is
server-blocked until ownership is verified). Once the site owner completes a
verification method (DNS TXT, HTML meta token, bridge token, repo connector,
or platform API approval), the site becomes `TAYA_CONNECTED` and
`publishContentMap` promotes drafts to published values, which this bridge
serves via `/api/bridge/content`.

## Source of truth

The canonical constants live in `convex/lib/webBridgeContract.ts`. This
